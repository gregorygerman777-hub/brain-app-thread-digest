# Thread Digest

Paste a long conversation and get its decisions, open questions and next steps.

A brain app for [BRAINF](https://github.com/gregorygerman777-hub/BRAINF). It runs as a tab
(`/digest`) inside your brain and talks to it through the console's app bridge.

- Permissions: `llm.invoke`, `memory.write`
- Memory layers: episodic (read), semantic (append)

## Install

In your brain: **Settings > Apps**, paste
`https://github.com/gregorygerman777-hub/brain-app-thread-digest` and approve.

## Files

- `brain-app.yaml`: the manifest (`brain-app/v1`)
- `dist/index.html`: the whole app, no build step
